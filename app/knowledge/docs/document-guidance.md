# Replacing an incorrect upload
If you uploaded the wrong document, look for a replace or re-upload option in the portal before final submission. After submission, contact the Admissions Office; do not email sensitive documents unless the official channel asks you to.

# Marks card not yet available
If a marks card is not available yet, ask the Admissions Office whether a provisional document or a later submission is accepted for your programme. Do not assume it is allowed.

# File size and formats
Accepted file formats and the maximum file size are not specified in this demo knowledge base. Check the portal's upload screen for the current limits.
