# Application statuses
Statuses shown by the applicant portal and what each generally means:
- Application Incomplete: the form has been started but not fully submitted.
- Application Submitted: the application was received and is waiting for review.
- Under Review: the admissions team is reviewing the application.
- Shortlisted: the application has progressed to the next selection stage. This is not an admission offer.
- Application Rejected: the application was not successful.
A status never means you are selected unless an offer is explicitly shown.

# Login and password problems
If you cannot log in, use the "Forgot password" option on the portal sign-in page to reset your password. If the OTP does not arrive, wait a few minutes, check spam/junk folders, then request a new OTP once. If the problem continues, contact the Admissions Office.

# Duplicate accounts
If you accidentally created two applicant accounts, do not submit two applications. Contact the Admissions Office so the duplicate can be merged or deactivated.
